## Broke
- GitHub Projects board was blocked until the developer added the `project` scope (`gh auth refresh -h github.com -s project`; the `-h` is needed when run from Claude Code's `!` prompt). Fixed.
- Data issues while fetching the prototype data: missing population (Tofino), several elevations per place (Hobart, Everest), API rate limits. Fixed in the script and logged in [[Data Pipeline#Known data issues]].
- First PDF render spilled every third row onto its own page (10.5 in of cards on a 10 in printable area). Fixed with smaller top and bottom margins.
- Renaming board cards for the name decision: a script mis-renamed two cards (Windows line endings broke the title match). Fixed by hand the same day.
- First Wikidata class match was too loose: Greektown passed as a "town" and a Quebec City neighbourhood as a "city". Fixed with prefix matching and a Wikipedia-article requirement.
- The first landmark pull missed Lake Louise (Alberta) because Wikidata calls it a "glacial lake". Added 26 narrower classes.
- A vault-update script failed on a quoting error after the step 3 commit; redone in a follow-up commit.
- The structures query timed out on query.wikidata.org (single query and in batches). Moved it to QLever.
- Editing a regex through a shell one-liner turned `\b` into a backspace byte, so the exclusions silently stopped working (everything kept). Caught by the counts, fixed at the byte level.
- Preview map: province outlines first came out at 13 MB (171,000 tiny pieces); dropped islets and lake holes (0.37 MB). Three Wikidata items had no name; used the Wikipedia title. Phone layout overflowed from the canvas size; fixed.
- Flagged for Phase 2: the roadmap's minting code keeps the counter in `mintCounts/{cardId}`, while the collection list puts `minted` on `cards`. Noted in [[Architecture]].
